# Lab 3A · Crypto-Shredding (online version)

A static website: the lab page from `lab3a_crypto_shredding/crypto_shredding_lab.html`
with a short data notice on the start page. No server, no database. Students' answers stay
in their own browser until they hand them in with **Copy** or **Download** on the last page.

```
index.html   the whole lab
```

## Put it online (one time)

In a terminal in this folder:

```
npx vercel login
npx vercel --prod
```

Accept the defaults. Vercel prints the link to give students, for example
`https://lab3a-crypto-shredding.vercel.app`.

## Update it later

Edit `index.html`, then run `npx vercel --prod` again. The link stays the same.
